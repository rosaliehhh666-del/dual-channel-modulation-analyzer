# 个人贡献：FPGA 采集与数字信号处理

本页为团队项目中的个人工作说明。依据上游 README 已公开分工，YiHuan15 负责 FPGA RTL 与数字信号处理；YiHuan15 与本仓库维护者 rosaliehhh666-del 为同一成员。RK3506 板端应用主要由 Creamy-coffee 负责。

## 负责范围与代码入口

| 工作 | 实现入口 | 设计关注点 |
|---|---|---|
| 双通道 ADC 同步采集 | `fpga/rtl/ad9238_capture.v` | 同边沿锁存、偏移二进制转二补码、启动与复位、OTR |
| 多速率频谱分析 | `fpga/rtl/multirate_fft_frontend.v`、`fft_frame_4ch.v` | CIC/FIR 抽取、4096 点 FFT 时分复用、定点缩放 |
| 数字下变频 | `fpga/rtl/ddc_nco_mixer.v`、`ddc_cic_decimator.v`、`ddc_fir_decimator.v` | 正交混频、抽取、滤波和有效性传播 |
| 频率捕获与锁相 | `fpga/rtl/freq_scan_ctrl.v`、`local_afc_2ch.v`、`lockin_core_2ch.v` | 粗估与局部跟踪、幅相计算、结果资格 |
| 谐波分析 | `fpga/rtl/harmonic_power_store.v`、`isqrt_u64.v` | H1～H5、定点功率及有限阶 THD |

主要职责不代表每个文件均由个人从零独立编写。模块的具体修改以原始提交 diff 为准，交叉协作与 AI 辅助过程保留在开发记录中。

## 可核对的工程结果

- 双通道 12 位、每路 65 MSPS 采集；这是 ADC 采样率，不是 UART 连续上传率。
- FPGA 实现 `a222905e`：20294 LUT、13111 FF、80 DSP、等效 36 块 BRAM；WNS +0.172 ns，WHS +0.010 ns。原件见 `fpga/build_evidence/`。
- 共享 4096 点 FFT 与多速率前端；FPGA SPEC 使用固定 Hann，屏端 RAW 频谱提供 Hann / Blackman / FlatTop 三窗。
- H1～H5 与 THD₂₋₅已有指定条件功能测试；未宣称可溯源精密校准。
- 数字判决分层：FPGA 提供采集/DDC及分析数据，屏端完成选路 OOK / 2FSK / BPSK 判决；QPSK 当前屏端仅 I/Q 观测。

## 面试时可展开的设计取舍

1. **资源与吞吐**：为什么选择共享 FFT？讨论 35T 资源、蝶形复用、样点缓存及输出帧率，区分采样与显示吞吐。
2. **定点数值**：逐级缩放、溢出、舍入如何影响弱信号与谐波读数？用源码和仿真说明。
3. **跨模块有效性**：为什么收到一帧不等于测量有效？说明 CRC、配置回显、滤波预热、资格和结果年龄的不同作用。
4. **验证分层**：RTL 仿真、实现时序、真实抓包、屏幕观察分别证明什么？精密校准为何还需要参考条件？
